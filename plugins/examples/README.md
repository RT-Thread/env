# Env plugin examples

The example projects cover the supported phase-two plugin shapes:

- `build-insight-1.0.0/`: WebUI + CLI plugin with a host theme handshake.
- `quality-gate-1.0.0/`: WebUI-only plugin.
- `probe-flash-0.9.6/`: CLI-only plugin.
- `hello-1.0.0/` and `hello-1.1.0/`: lifecycle and upgrade fixtures.

Ready-to-install example packages are stored in `prebuilt/`. See the README in
each source project for reproducible build and local installation commands.
